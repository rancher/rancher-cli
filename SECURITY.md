# Security policy

Do not report a security issue in a public issue or pull request.

Email security-rancher@suse.com with the details. Include the rancher-cli
version (`rancher --version`), your operating system and the steps to
reproduce. Remove tokens and passwords from anything you send.

For a vulnerability in Rancher itself, see the
[Rancher security policy](https://github.com/rancher/rancher/security).
